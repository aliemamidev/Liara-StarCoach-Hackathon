## Project summary

Liara Documentation Companion is a three-day hackathon prototype that adds an AI-assisted support layer and an administration workflow to an adapted Liara documentation project. It combines documentation retrieval, the Lia Agent, persisted chats, verified knowledge, escalation tickets, and operational reporting.

## Scope

The project is intended to help users find relevant Liara documentation, understand likely solutions, and reach a human when evidence is insufficient. It includes an admin dashboard for reviewing chats, answering escalations, and promoting validated answers into a searchable knowledge base.

Competition prototype only. It was written in three days and must not be treated as production-ready software. See [`README.md`](./README.md) and [`LICENSE`](./LICENSE) for architecture, limitations, attribution, and permission requirements.
