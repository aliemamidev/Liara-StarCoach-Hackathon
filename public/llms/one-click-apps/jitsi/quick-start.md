# راه‌اندازی سریع برنامه‌های Jitsi

Jitsi Meet یک پلتفرم Open Source برای ویدئوکنفرانس است که بر پایه‌ی WebRTC ساخته شده و امکان برگزاری جلسات صوتی و تصویری، Screen Sharing، Chat، Poll، Reactions و قابلیت‌هایی مانند Virtual Background را در مرورگر فراهم می‌کند. همچنین SDKهای Web و Native دارد و می‌توان آن را مستقیماً داخل یک وب‌اپلیکیشن Embed کرد.

## راه‌اندازی برنامه

برای راه‌اندازی Jitsi با استفاده از Liara Console، مراحل زیر را انجام دهید:

1. وارد حساب کاربری خود در کنسول لیارا شوید.
2. حساب شخصی یا تیمی موردنظر را برای راه‌اندازی برنامه انتخاب کنید.
3. در منوی برنامه‌های آماده، برنامه‌ی Jitsi را انتخاب کنید و از نصب سریع یا نصب پیشرفته استفاده کنید.
4. در نصب سریع، نام برنامه را وارد کنید و روی نصب و راه‌اندازی بزنید. لیارا برای برنامه یک شناسه‌ی منحصربه‌فرد، شبکه‌ی خصوصی، پلن سخت‌افزاری و بسته‌ی امکانات پیش‌فرض ایجاد می‌کند. وضعیت برنامه را می‌توانید در بخش رویدادها و لاگ‌ها بررسی کنید.

## پیکربندی Jitsi

پس از ساخت برنامه، در بخش سرور مجازی ابری، برنامه‌ی Jitsi را انتخاب کنید و از بخش اتصال، طبق مستندات اتصال به سرور با SSH، به سرور متصل شوید. سپس دستورات زیر را اجرا کنید:

```bash
cd /opt/jitsi
docker compose exec prosody bash
```

در ادامه، به‌جای `User` و `YourPassword` نام کاربری و رمزعبور خود را قرار دهید:

```bash
prosodyctl --config /run/prosody/config/prosody.cfg.lua register User meet.jitsi YourPassword
```

در پایان می‌توانید با آدرس `https://IP` وارد برنامه‌ی Jitsi شوید؛ به‌جای `IP`، آدرس IP برنامه‌ی خود را وارد کنید.
